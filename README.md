# Yams

Cinq dés, trois lancers par tour et treize cases à remplir. 63 points en haut de la feuille donnent 35 de bonus.

À chaque tour, lance les dés jusqu'à trois fois en gardant ceux que tu veux, puis inscris le résultat dans une case libre : les chiffres, brelan, carré, full, petite et grande suite, Yams et chance.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Yams → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
